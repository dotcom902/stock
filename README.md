# 🤖 AI-Driven Swing Sniper (AI 量化波段狙擊系統)

這是一套結合「傳統量化技術面指標」與「生成式 AI (Gemini 2.0 Flash) 深度基本面判讀」的全自動美股波段交易雷達。系統每日於盤後自動運行，精準捕捉市場資金輪動，並提供高勝率的期權與正股操作 SOP。

## 🧠 核心架構與交易邏輯 (Trading Logic)

本系統採用 **「漏斗式過濾架構 (Sniper Strategy)」**，透過四個階段將市場雜訊降至最低：

### Phase 1: 動態資金池 (Dynamic Universe Generation)
系統不依賴靜態觀察清單，每日自動構建三層監控池：
1. **基準底倉**：Nasdaq 100 成分股 (捕捉大型權值股錯殺機會)。
2. **個人持倉**：自定義 `MY_PORTFOLIO` (自動進行持倉健康度監控)。
3. **AI 動態熱門板塊**：呼叫 Gemini AI 判讀當日總經與資金流向，自動選出 3 大最具爆發力的板塊與代表股票（如：先進封裝、太空科技、比特幣概念），確保雷達永遠瞄準市場最熱資金。

### Phase 2: 量化技術面初篩 (Technical Signal Engine)
針對資金池內的股票，計算 20 日移動平均線 (20MA)、乖離率 (Bias)、相對強弱指數 (RSI) 與 相對成交量 (RVOL)。
並依據股票屬性，給予不同的型態判定：
* **🔥 熱門板塊專屬邏輯**：不接破底刀！只抓資金湧入的 **「動能突破 (RSI > 65 + RVOL > 1.2x)」** 或洗盤結束的 **「強勢回檔 (RSI 40~55 + 守住均線)」**。
* **📊 一般權值股邏輯**：捕捉市場情緒錯殺的 **「超跌反彈 (RSI < 35 + 負乖離過大)」**。

### Phase 3: 狙擊手評分與限流機制 (Top 5 Sniper Filter)
為防止 AI 幻覺與 API 額度耗盡，系統內建評分機制機制：
* **基本面評分**：爬取最新新聞標題與目標價，若含利多關鍵字 (Upgrade, Beat) 則加分，利空則扣分。
* **熱度加權**：結合基本面評分與 RVOL 計算最終 `sort_weight`。
* **Top 5 鎖定**：無論大盤崩跌觸發多少標的，系統**每日僅允許將排名最高的前 5 檔股票**送入下一階段交由 AI 審查，大幅提升執行效率與精準度。

### Phase 4: AI 一票否決與 SOP 派發 (AI Veto & SOP Generation)
將 Top 5 標的的量化數據與最新 5 則催化劑新聞送交 Gemini AI 進行邏輯審查：
* **否決權 (Veto Power)**：若 AI 判讀利空為「結構性破壞 (如：財報暴雷、假帳、核心掉單)」，直接判定【高風險避開】，推翻技術面買進訊號。
* **自動 SOP 提示**：根據最終型態與財報日，自動產出交易指令：
    * 🥇 **情境 A (熱門股強勢回檔)**：建議建倉 Bull Put Spread (賣權多頭價差) 鎖住下檔風險。
    * 🥈 **情境 B (帶量動能突破)**：建議追擊正股/買 Call，並嚴格設定 8%~10% 移動停損。
    * 🥉 **情境 C (優質權值股錯殺)**：建議保守 Sell Put 爽收超額權利金。
    * 🛑 **絕對避開**：AI 否決或財報即將發布 (5日內) 者，強制觀望。

## 🛡️ 系統防護機制 (System Robustness)
* **反爬蟲裝甲**：底層採用 `curl_cffi` 完美偽裝 TLS 指紋，突破 Google News 與 Yahoo Finance 的機器人阻擋。
* **網址加密防破壞**：採用 Base64 編碼核心 URL，防止 GitHub Markdown 編輯器自動轉換超連結導致爬蟲失效。
* **指數退避重試 (Exponential Backoff)**：完美捕捉並處理 API 的 `429 Too Many Requests`，確保在高併發下仍能穩定完成所有分析任務。
